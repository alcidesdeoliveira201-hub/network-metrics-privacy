Network Metrics

Uses YouTube API Services
Privacy PolicyTerms of Service

Network Metrics is a private desktop tool (Python scripts) used only by its owner to manage the owner's own YouTube channels: Auto in Arrivo, Last One Out, Blackout Ready, Coches en Camino and Vanished Record.

What it does

  • Uploads the owner's own original videos and sets title, description, tags, captions and custom thumbnails.
  • Schedules the publication time (videos stay private until the scheduled time).
  • Posts one credits comment per video (image and source attributions).
  • Reads the owner's own channel analytics (YouTube Analytics and Reporting APIs) for internal performance reports.

Access

The tool runs only on the owner's computer, uses Google OAuth 2.0 with the minimum scopes needed, and has no other users. Access can be revoked at any time at myaccount.google.com/permissions.
